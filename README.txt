COFish production icon package

Files:
- cofish-logo.svg — corrected master vector
- favicon.ico — multi-resolution browser favicon
- favicon-16x16.png, favicon-32x32.png, favicon-48x48.png, favicon-64x64.png
- apple-touch-icon.png — iOS home-screen icon
- android-chrome-192x192.png and android-chrome-512x512.png
- safari-pinned-tab.svg — monochrome Safari mask icon
- mstile-150x150.png and browserconfig.xml — Windows tile support
- site.webmanifest — web app metadata
- cofish-social-preview-1200x630.png — social sharing preview
- html-head-snippet.txt — tags to add inside the page <head>

Place these files in the repository root so the absolute paths in the manifest and HTML work at COFish.app.
